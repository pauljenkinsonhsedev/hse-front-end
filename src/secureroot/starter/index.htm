Local development

This is the starter page. You're seeing it because there is no src/secureroot/html/index.htm yet.

Build your pages here

Put the pages you want to test in src/secureroot/html/. Every .htm and .json file in that folder is copied to secureroot/hseonline/website/livelive/secureroot/ and served from there.

Add your own src/secureroot/html/index.htm, for example a copy of the real homepage, and it replaces this page.

Everything in src/secureroot/html/ is git-ignored, so pages you add stay on your machine.

How it works

  • npm run dev builds everything, then watches the source and serves the site at http://localhost:8080
  • SCSS in src/secureroot/v6-css/ builds to assets/v6-css/{{version}}.min.css
  • JavaScript in src/shared/js/ builds to assets/v6-js/main-{{version}}.min.js
  • Dreamweaver templates (.dwt) are in src/templates/
  • npm run ds builds and serves the design system instead

See README.md for the full set of scripts.
